- 对传感器、图片和病害风险校验实际时间、质量、有限数、单位及所属地块；未评估不表述为无风险。

- 真实设备自动启动要求端侧定时、失联停止、执行编号去重和匹配回执的明确契约。没有完整接线的协议保留自动启动门禁。

- 排期保存稳定执行编号；依赖动作等待同编号的实际完成证据；下发中进程中断的动作转待核验，不在重启后自动重发。
- 效果复查分别核对作业完成和实际维护效果，观测必须晚于本轮结束及基线。失败或缺证据生成告警，不假报维护成功。
- 复查停止前在设备锁内重新核对新鲜状态与原执行编号，防止误停后来作业；人工普通停止兼容旧状态。
- 通知送达与人工确认分开，失败有界退避，明确拒收不能因 HTTP 200 被标为送达；并发领取也遵守退避。
- 调度配置、进程心跳、维护管道最近成功及失败分别显示。进度与向导可绑定同用户地块，拒绝布尔编号和越权绑定。
